# MetaSAG-Core-Code
A modular pipeline for taxonomic and functional analysis of microbial single-amplified genome (SAG) sequencing data, enabling strain-resolved microbiome and phage-host interaction studies.

# MetaSAG - Source Code for Review

This repository contains the **complete, unencrypted source code** of MetaSAG for peer review purposes.

## Relationship with the public repository

- **Public repository (function & installation):** https://github.com/liangcheng-hrbmu/MetaSAG
  - Provides the installable Python package
  - Includes documentation, usage examples, and feature descriptions
  - The source code in the public repository is not fully open to protect core methodology prior to formal publication

- **This repository (source code for review):** https://github.com/HMU-ZSN/MetaSAG-Core-Code
  - Contains the **full source code** for transparent evaluation by reviewers
  - Allows inspection of all modules, functions, and implementation details

## Publication plan

Upon acceptance of the manuscript, the complete source code will be made publicly available at the official GitHub repository: https://github.com/liangcheng-hrbmu/MetaSAG
